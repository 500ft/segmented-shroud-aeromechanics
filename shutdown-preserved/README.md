# Shutdown preservation

These files are copies of existing project work saved at the owner’s request.
No research, CAD work, experiments or result edits were performed for this snapshot.
The adopted external FINAL_PLAN.md supersedes the old plans in these copies.

Each source worktree has its own folder. These snapshots retain their original
contents and may be incomplete. Paths inside them were not rewritten. To recover
work, use the source commit and original path in [manifest.json](manifest.json).
The geometry folder includes the existing generated exports.

The manifest lists original paths, source commits, byte counts, SHA-256 hashes,
checked repositories and exclusions. Original files and branches remain intact.
