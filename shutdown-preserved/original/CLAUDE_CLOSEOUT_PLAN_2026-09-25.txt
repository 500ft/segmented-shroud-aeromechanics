B2. Concrete candidate design and numerical audit.

Recommendation: replace the unspecified resolution-IV design with an explicit three-factor quadratic candidate using the 13 unique locations of a three-factor Box-Behnken layout. This is a proposed response-surface design, not a claim that the physical response is quadratic and not an already-approved run release. It avoids pretending that identical deterministic centre runs create replication.

Factors and coding:
  x = n - 3, for seam count n in {2,3,4}.
  y = (F-F_mid)/F_half, where F is total open angular fraction,
      F_mid=(F_low+F_high)/2, F_half=(F_high-F_low)/2.
  z = 2*s/s_high - 1, where s is a nonnegative registered radial-step magnitude.
  Each equal-width seam has w=2*pi*F/n radians; physical width g must name its radius/convention.

F_low, F_high and s_high are prospective physical inputs. Require 0<F_low<F_high<1, nonoverlap, minimum wall ligament and positive rotor-envelope clearance with registered margins. The operational range will be much narrower if geometry, metrology or compute require it. Do not set numerical ranges from an unobserved effect prediction.

Use the existing equal-wall-mean step construction with a precisely defined s. One candidate for equal segment lengths: n=2 or 4 alternates offsets -s/2,+s/2; n=3 uses offsets -s/2,0,+s/2 with a registered angular placement. The mean offset is zero and maximum adjacent jump is s, but jump distribution differs. Record the full offset vector: count/step interactions may reflect that construction. If the intended step definition differs, revise the mapping before using this matrix. The s=0 contrasts isolate redistribution without this extra step-pattern change.
